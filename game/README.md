# GORE ZONE — рэгдолл-песочница для iPhone и Android

3D-игра от первого лица (HTML5 + three.js), всегда горизонтальная (в портретном режиме экран поворачивается сам). Работает на iPhone (Safari) и Android (Chrome). Устанавливать через магазин не нужно.

## Как запустить на телефоне
1. Включи GitHub Pages: Settings → Pages → Source: «Deploy from a branch» → выбери ветку и папку `/ (root)`.
2. Открой на телефоне `https://<твой-ник>.github.io/Project-angel0/game/`.
3. Добавь на главный экран, чтобы игра открывалась на весь экран как приложение:
   - **iPhone:** Safari → «Поделиться» → «На экран Домой».
   - **Android:** Chrome → ⋮ → «Добавить на главный экран».

## Что есть
- Главное меню, настройки (кровь, число людей, режим «Хаос», звук), экран «Как играть», пауза
- 3 карты: Ночной город, Склад, Каньон
- 9 видов оружия: кулаки, нож, бита, катана, пистолет, дробовик, автомат, граната, РПГ
- Тела-рэгдоллы, кровь остаётся на земле, катана и взрывы отрубают конечности
- Бандиты нападают, мирные жители убегают или дают сдачи
- Убитые остаются на карте; оживить можно Реалити-крашером или включить возрождение в настройках (30 с / 1 мин / 3 мин)


`index2d.html` — старая 2D-версия.

- Граффити: баллончик и маркер, 10 цветов. Новое меню, арсенал по категориям.
- v4: расчленёнка у живых, раны, лужи крови, топор, бензопила, снайперка, патроны и прицел, режим «Выживание», экран «Арсенал».
- v5: Реалити-крашер (создать, захват, толчок, оживить, удалить), пустая карта при старте, полёт и бессмертие в песочнице, карта «Полигон», физические ящики и взрывные бочки.
- v6: новый интерфейс — белый минималистичный HUD, колесо оружия, каталог создания для крашера (вооружённые бандиты).

## APK и EXE
- `build/build-apk.sh` — собирает `GoreZone.apk` (Android 5+, WebView, игра работает без интернета).
  Нужно: `apt install aapt apksigner zipalign dalvik-exchange android-sdk-platform-23 default-jdk`.
- `build/build-exe.sh` — собирает `GoreZone.exe` (Windows 10/11, 64 бит): своё окно игры на WebView2, без консоли, с иконкой. F11 — полный экран.
- `build/build-installer.sh` — собирает установщик `GoreZone-Setup.exe` (ярлыки на рабочем столе и в «Пуске», удаление через «Приложения»). Нужно: `apt install nsis`.
- v1.0 (финальная): все экраны помещаются на маленьких телефонах, баланс «Выживания», пауза при выходе из захвата мыши, смена оружия колёсиком.
- Звук: синтезированные выстрелы, удары, хруст, крики, шаги, окружение карт, музыка в меню, пространственное стерео и эхо.
- Физика: вес частей тела, ограничения сгибания суставов, трение, засыпание тел, столкновения тел друг с другом, трупы можно пинать, ящики и бочки — толкать.
- Голова разлетается на глаза, челюсть с зубами, мозг и куски черепа; у лиц есть рот.
